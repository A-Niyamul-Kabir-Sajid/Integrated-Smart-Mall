# Project context

Integrated Smart Mall / 3 2 SyStem is a KUET university project serving customers, shop owners and mall administrators through one browser-based application.

The user selected Laravel 13, a modular monolith using MVC and a service layer, PostgreSQL, Blade with JavaScript/Alpine.js initially, and Three.js/WebXR for navigation experiments. Laravel is already installed at the repository root. Exact installed versions should be checked from the lockfile/runtime when needed; do not create another application.

The intended flow is checkpoint scan, directory/product search, route selection, ordinary map guidance and optional validated AR guidance, followed by normal or purchase-verified reviews. Customer assistance and management reports consume maintained records.

The [full feature catalogue](references/functional/DOC/project/FEATURE_CATALOGUE.md) preserves the wider product scope. Its optional/later features are not automatically first-release commitments. The [historical context](references/functional/DOC/project/PROJECT_CONTEXT.md) records device, timeline and feasibility questions; its old unconfirmed-stack statements are superseded by the user's Laravel selection.

QR checkpoint identity does not establish continuous positioning. WebAR needs device evidence. Forecasting needs suitable data. External payment/POS/parking integrations remain subject to separate scope and provider decisions.
