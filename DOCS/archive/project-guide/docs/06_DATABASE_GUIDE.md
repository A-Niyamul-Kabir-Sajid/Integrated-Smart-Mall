# 06 — Database Guide

PostgreSQL is the recommended primary database. The existing ERD package remains authoritative for current entity/relationship detail until an approved migration changes it.

## Before any schema change

Read the imported database conventions, table ownership, cross-module relations, constraint enforcement, data lifecycle, open decisions, the affected module `BUSINESS_RULES.md`, `DATA-DICTIONARY.md`, and ERD.

## Import destination

The merge script copies existing database-level documents into `docs/database/legacy-authoritative/` and module ERD assets into the corresponding canonical module folders. No ERD is regenerated by this guide package.
