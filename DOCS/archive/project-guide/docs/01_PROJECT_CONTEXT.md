# 01 — Project Context

**Project:** 3 2 SyStem / Integrated Smart Mall

A browser-based smart mall platform for customers, shop owners and mall administrators. Its core software scope includes searchable mall/shop/product information, QR checkpoint initialization, custom indoor maps, A*/Dijkstra multi-floor routing, optional WebAR guidance, purchase verification, reviews, bounded chatbot/RAG assistance, and operational analytics/reporting.

## Scope discipline

- Navigation and ordinary web workflows are implementation targets.
- Continuous WebAR positioning, external POS/payment integration, live sensor-derived parking/footfall, and forecasting should be isolated as prototype/integration tracks unless later promoted by an approved decision.
- The architecture must remain useful even when WebAR or an external provider is unavailable.
