# Suggested build order

Top-level module structure follows the catalogue; implementation can still proceed in vertical slices.

1. M12 shared foundation; minimum M10 approved mall/shop records and M08 catalog; M01 guest/account basics.
2. M02 discovery plus M03 custom map/QR/graph route. Start M03 WebAR device/localization experiments immediately alongside this flow.
3. M03 multi-floor/accessibility and measured WebAR integration; M05 normal/verified review using minimum M04 purchase evidence and M08 authorized registration.
4. M06 customer assistant and M11 monthly reporting; M09 initial shop metrics.
5. Expand M07 support, M08 operations, M10 maintenance/moderation and validated M09/M11 forecasts.
6. Implement remaining shopping, full inventory, payments, loyalty, parking occupancy, tenant financials and external integrations only when scheduled and supported by required data/services.

The attachment's original priority table remains in FEATURE_CATALOGUE.md. Nine-week milestones and the longer project timeline need explicit scheduling; this order is not a commitment that every catalogued feature fits the initial milestone.
